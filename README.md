# LearnNest 🎓

> AI-powered learning assessment platform for parents and children.

## What it does
Parents upload study material (PDF or text). AI generates questions.
Parents assign questions to their child. Child submits answers.
AI evaluates answers and gives feedback.

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React, TypeScript, TailwindCSS, Vite |
| Backend | Python, FastAPI, PostgreSQL |
| AI | Anthropic Claude API |
| Storage | Cloudinary |
| Deploy | Docker, Render, GitHub Actions |
